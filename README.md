# Локальный менеджер паролей

Безопасный локальный менеджер паролей с зашифрованным хранилищем на Python. Использует современные криптографические алгоритмы для защиты ваших паролей.

## Особенности

- **Безопасное шифрование**: Argon2id для KDF, AES-256-GCM для шифрования данных
- **Двухуровневое шифрование**: Envelope encryption с отдельными ключами для данных и обёртки
- **Два интерфейса**: CLI для автоматизации и GUI для удобного использования
- **Генератор паролей**: Создание безопасных паролей и passphrase
- **Авто-лок**: Автоматическая блокировка хранилища по таймеру
- **Поиск и категории**: Быстрый поиск записей и организация по категориям
- **Экспорт/импорт**: Поддержка экспорта и импорта в JSON и CSV

## Установка

### Требования

- Python 3.8 или выше
- pip

### Установка зависимостей

```bash
pip install -r requirements.txt
```

Зависимости:
- `cryptography>=41.0.0` - криптографические примитивы
- `argon2-cffi>=23.0.0` - Argon2id KDF

### Опциональные зависимости

Для работы с буфером обмена на Windows:
```bash
pip install pywin32
```

Для работы с буфером обмена на Linux:
```bash
sudo apt-get install xclip
# или
pip install pyperclip
```

## Использование

### GUI интерфейс (по умолчанию)

Запуск графического интерфейса:

```bash
# Из корня проекта:
python run.py
# или

```

При первом запуске будет предложено создать новое хранилище. Хранилище по умолчанию создаётся в `~/.password_manager/vault.vault`.

### CLI интерфейс

Запуск командной строки:

```bash
# Из корня проекта:
python run.py --cli <команда>
# или
python -m src.main --cli <команда>
```

#### Команды CLI

**Создание хранилища:**
```bash
python run.py --cli init
# или
python -m src.main --cli init
```

**Добавление записи:**
```bash
python run.py --cli add --title "GitHub" --username "user@example.com" --generate --length 20
```

**Список всех записей:**
```bash
python run.py --cli list
```

**Просмотр записи:**
```bash
python run.py --cli get <entry_id> --copy-password
```

**Редактирование записи:**
```bash
python run.py --cli edit <entry_id> --title "Новое название"
```

**Удаление записи:**
```bash
python run.py --cli delete <entry_id>
```

**Поиск записей:**
```bash
python run.py --cli search "github"
```

**Генератор паролей:**
```bash
python run.py --cli generate --length 24 --copy
```

**Генератор passphrase:**
```bash
python run.py --cli generate --passphrase --words 6 --separator "-"
```

**Экспорт хранилища:**
```bash
python run.py --cli export backup.json --format json
python run.py --cli export backup.csv --format csv
```

**Импорт записей:**
```bash
python run.py --cli import backup.json --format json
```

**Смена мастер-пароля:**
```bash
python run.py --cli change-password
```

## Формат хранилища

Хранилище представляет собой бинарный файл со следующей структурой:

### Заголовок (не зашифрован)

- **Magic bytes**: `BRNGVLT1` (8 байт) - идентификатор формата
- **Format version**: версия формата (uint16)
- **KDF type**: тип KDF (uint8, 1 = Argon2id)
- **KDF params**: параметры KDF (memory_cost, time_cost, parallelism)
- **Salt**: случайная соль (32 байта)
- **DEK nonce**: nonce для обёртки DEK (12 байт)
- **Wrapped DEK**: зашифрованный DEK (переменная длина)
- **Encrypted payload length**: длина зашифрованных данных (uint32)

### Payload (зашифрован)

JSON структура с записями паролей:

```json
{
  "entries": [
    {
      "id": "uuid",
      "title": "encrypted",
      "username": "encrypted",
      "password": "encrypted",
      "url": "encrypted",
      "notes": "encrypted",
      "category": "encrypted",
      "tags": ["encrypted"],
      "created_at": "iso_timestamp",
      "updated_at": "iso_timestamp"
    }
  ],
  "metadata": {
    "version": 1,
    "created_at": "iso_timestamp"
  }
}
```

**Важно**: Все поля записей (кроме метаданных) зашифрованы для минимизации утечек информации.

## Безопасность

### Криптография

- **KDF**: Argon2id с параметрами по умолчанию (memory_cost=65536, time_cost=3, parallelism=4)
- **Шифрование**: AES-256-GCM для данных и обёртки ключей
- **Envelope encryption**: DEK шифрует данные, KEK (выведенный из мастер-пароля) обёртывает DEK
- **Уникальные nonce**: Каждое шифрование использует случайный nonce

### Рекомендации по безопасности

1. **Мастер-пароль**: Используйте сильный мастер-пароль (минимум 8 символов, разнообразные типы символов, высокая энтропия)
2. **Резервные копии**: Регулярно создавайте резервные копии файла хранилища
3. **Авто-лок**: Включите авто-лок в GUI для автоматической блокировки при бездействии
4. **Буфер обмена**: Пароли автоматически очищаются из буфера обмена через 30 секунд
5. **Физическая безопасность**: Защитите файл хранилища от несанкционированного доступа

### Ограничения

- **Память**: Ключи хранятся в памяти во время работы приложения (это неизбежно для функциональности)
- **Буфер обмена**: Автоочистка буфера обмена работает на уровне "best effort" - некоторые системы могут сохранять историю буфера
- **Метаданные**: Размер файла и время последнего изменения могут раскрывать информацию о хранилище
